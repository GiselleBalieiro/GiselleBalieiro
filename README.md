## 🚀 Featured Projects

> 🔒 = private repository (code not public). I'm happy to walk through it in an interview.

### 🎧 Listening Platform 🔒
A dictation app for practicing English listening. You paste a YouTube video, hear one sentence at a time, type what you heard, and only move on when it is correct.

- **Stack:** Angular 21 · NestJS · PostgreSQL + pg-boss · Docker · Vercel · MCP SDK
- **What I built (solo, ~90 commits, 7 PRs):**
  - Spaced review, easy/medium/hard dictation modes, a personal dictionary and a diary with a translation helper.
  - A transcription worker on a job queue that fetches subtitles with yt-dlp.
  - A **remote MCP server**, so an AI assistant can create lessons and analyze the learner's progress.
  - Auth with sessions and personal tokens, captcha, honeypot and rate limiting.
  - DB migrations that are safe to run from several instances at once.
  - Multi-stage Docker images for the API, worker and web app.
  - Moved the front end from Next.js to Angular.

### 🤖 AgenT + IA RAG API 🔒
A SaaS for creating custom AI agents that answer customers on WhatsApp.

- **Stack:** React · Vite · Tailwind · Node/Express · RAG (embeddings + vector store) · OpenRouter · Baileys · MySQL · MongoDB · JWT · Railway
- **What I built (solo, ~150 commits):**
  - A dashboard to set each agent's identity, training data and WhatsApp connection (by QR code), plus a test panel.
  - A RAG pipeline over each agent's training text.
  - Lead qualification controlled by code, so the agent always collects the required data.
  - Conversation history stored in the DB.
  - Roles and permissions.

### 💰 Financial System 🔒
A white-label finance platform with:
- accounts payable and receivable, suppliers and bank accounts;
- cash-flow dashboard and budget vs. actual;
- credit-card billing cycles;
- bank-statement import from **OFX, CSV and PDF**, with duplicate detection.

- **Stack:** TypeScript · Express 5 · MongoDB · Zod · Vitest · Vercel serverless · React · TanStack Query · Recharts

### 🧁 Delicie: Bakery Website 🔒 (client project)
Marketing site and online menu for a real bakery, with orders sent straight to WhatsApp, seasonal pages and Google Tag Manager conversion tracking.

- **Stack:** Next.js · React · TypeScript · shadcn/ui · OpenAI gpt-image-1
- **Extra:** a script that generates the menu photos with AI and updates the code automatically.
